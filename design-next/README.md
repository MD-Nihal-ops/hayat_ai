# Hayat AI — Frontend-only prototype

Hayat AI visual interface using fictional local demo data. It does not connect to a database, AI model, OCR service, authentication provider, or backend API.

## Run locally
1. Install Node.js 24 or newer.
2. Open this folder in VS Code.
3. Run `npm install` and then `npm run dev`.
4. Visit http://localhost:3000.

All patient information is fictional demo content. Do not enter real medical information.
